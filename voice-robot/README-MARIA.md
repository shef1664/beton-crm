## 📞 ПЕРЕВОДЫ НА МЕНЕДЖЕРА

Мария автоматически передаёт звонок если:

1. ✅ Клиент просит менеджера явно
2. ✅ Клиент говорит конкретный срок (через час, сегодня, в пятницу)
3. ✅ Клиент готов заказать ("как оформить", "беру")
4. ✅ Клиент просит скидку / рассрочку
5. ✅ Большой объём (>20 м³)
6. ✅ Нужны спецусловия (договор, документы)
7. ✅ Межгород доставка (>100км)
8. ✅ Что-то непонятно / не ясно

## ⚙️ СЛЕДУЮЩИЕ ШАГИ

### Фаза 2: Деплой (завтра)

1. **Установить зависимости:**
   ```bash
   pip install anthropic requests
   ```

2. **Загрузить в Voximplant:**
   - Скопировать `voxengine-scenario.js` в Voximplant Application → Scenarios
   - Добавить Routing Rule для входящих SIP-звонков
   - Установить Application Properties (см. выше)

3. **Развернуть backend:**
   - Загрузить `maria-integration.py` на Render (`/api/voice/maria`)
   - Или запустить локально для тестирования

4. **Тестирование:**
   - Позвонить на номер Voximplant
   - Услышать приветствие Марии (женский голос Bella)
   - Провести диалог
   - Когда нужно — услышать передачу на менеджера

### Фаза 3: Мониторинг (неделя 1)

- Отслеживать звонки в AmoCRM
- Смотреть логи передач
- На опыте подстраивать правила передачи
