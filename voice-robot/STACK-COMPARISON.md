# Голосовой робот — сравнение стеков (для решения шефа)

## Что нужно

Бот, который принимает входящий звонок на бизнес-номер +7-3842-63-55-88,
ведёт диалог по тому же сценарию что и текстовый робот-квалификатор
(6 вопросов), записывает поля в AmoCRM и эскалирует горячий лид:
- В рабочее время → переводит звонок шефу/менеджеру
- Вне рабочего времени → шлёт карточку в Telegram

## 4 варианта

### Вариант 1: 🇷🇺 Voximplant Avatar (готовое решение)

**Что это:** Российская облачная телеком-платформа со встроенным AI-аватаром
(внутри ChatGPT / Яндекс GPT) + TTS/STT/SIP всё в одном.

**Стоимость:**
- Платформа: 0 ₽ (после регистрации даётся $25 на тесты)
- Звонок входящий: ~1-3 ₽/мин
- TTS озвучка: ~0.3-0.5 ₽/мин
- STT распознавание: ~0.3 ₽/мин
- AI Avatar: ~5-10 ₽/мин (включает LLM)
- **Итого 1 звонок ~5 мин: ~30-60 ₽**

**Плюсы:**
- Всё из коробки. Не нужно склеивать
- Российский провайдер — соблюдение 152-ФЗ автоматически
- SIP-номер сразу даётся
- Не нужен OpenAI (всё внутри РФ)
- Есть UI-конструктор сценариев

**Минусы:**
- Качество TTS среднее (РФ-голоса не топ)
- Привязка к платформе (vendor lock-in)
- LLM качество ниже Claude/GPT-4
- Цена дороже самосборки в долгосрок

**Срок запуска:** **2-3 дня**

**Интеграция с AmoCRM:** есть готовый коннектор в Voximplant App Store

### Вариант 2: ⚡ Voximplant + OpenAI Realtime API

**Что это:** Voximplant как SIP/TTS/STT layer + OpenAI Realtime API
(GPT-4o real-time voice-to-voice).

**Стоимость:**
- Voximplant телефония: ~3-5 ₽/мин (только SIP+звонок, без AI)
- OpenAI Realtime: ~$0.18/мин ~ 18 ₽/мин при курсе 100₽/$ (input + output)
- **Итого 1 звонок ~5 мин: ~100-115 ₽**

**Плюсы:**
- Лучшее в мире качество голоса и понимания (GPT-4o)
- Voice-to-voice без промежуточного TTS/STT — естественные паузы, прерывания
- Самая быстрая реакция (latency 300мс)
- Бот понимает интонацию (раздражение, торопливость)
- Гибкость промпта (наш Claude-сценарий легко портируется)

**Минусы:**
- В 2-3 раза дороже Voximplant Avatar
- OpenAI API нужно платить в долларах (валютный риск)
- Российские VPN-проблемы (OpenAI блокирует РФ)
- Нужен прокси или VPS в Европе для OpenAI запросов
- 152-ФЗ: данные клиента уходят в США (юр.риск для юрлица)

**Срок запуска:** **5-7 дней** (нужен VPS-прокси + бэкенд-склейка)

**Интеграция с AmoCRM:** через webhook на наш сервис

### Вариант 3: 🇷🇺 Voximplant + Yandex SpeechKit + Claude API

**Что это:** Voximplant SIP + Yandex SpeechKit для TTS/STT (отличное качество РФ-речи) + Claude API для логики.

**Стоимость:**
- Voximplant SIP: ~3-5 ₽/мин
- Yandex SpeechKit STT: ~0.2 ₽/мин
- Yandex SpeechKit TTS: ~0.3 ₽/мин (премиум 0.6 ₽/мин)
- Claude API: ~5-10 ₽ за диалог (текст)
- **Итого 1 звонок ~5 мин: ~30-50 ₽**

**Плюсы:**
- Лучшая русская речь (Yandex TTS бьёт всех на рынке РФ)
- Claude API даёт лучшую логику диалога (как у нас в роботе-квалификаторе)
- Один и тот же промпт что и для текстового бота
- Российский STT/TTS = 152-ФЗ ok
- Гибкость
- Claude API доступен в РФ напрямую

**Минусы:**
- Latency выше чем у Realtime API (STT → LLM → TTS ~ 1-2 сек)
- Больше склейки кода (3 сервиса)
- Нет voice-to-voice — прерывания клиента сложнее обработать

**Срок запуска:** **4-5 дней**

**Интеграция с AmoCRM:** через наш бэкенд

### Вариант 4: 🎁 Aimylogic (no-code конструктор)

**Что это:** Платформа Just.ai с готовым конструктором голосовых ботов.

**Стоимость:**
- Платформа: от 5 000 ₽/мес (Starter)
- Звонок: ~3-5 ₽/мин
- **Итого 1 звонок ~5 мин: ~30 ₽ + 5000₽/мес фикс**

**Плюсы:**
- No-code, шеф/менеджер могут сами править сценарий
- Готовые шаблоны для продаж
- Интеграция AmoCRM из коробки
- Быстрый запуск (1-2 дня)

**Минусы:**
- Меньше гибкости (конструктор сценариев)
- LLM-логика хуже Claude (свой движок понимания)
- Vendor lock-in
- Фикс 5000₽/мес даже если звонков мало

**Срок запуска:** **1-2 дня**

## Моя рекомендация

**Вариант 3: Voximplant + Yandex SpeechKit + Claude API**

Почему:
1. Та же LLM (Claude), что и в текстовом роботе → **один промпт, одна логика**
2. Лучший русский TTS (Yandex) — клиент не услышит «робот»
3. 152-ФЗ полностью соблюдён
4. Стоимость уровня дешёвых вариантов
5. Гибкость для расширения (добавим A/B-тестирование промптов, аналитику)

**Что нужно от шефа:**

1. **Voximplant аккаунт** — регистрация через https://manage.voximplant.com/registration
   - При регистрации $25 на тесты (хватит на ~200 минут)
   - Дальше пополнение на 1000-2000₽ для месячного теста
2. **Yandex SpeechKit** — у нас уже есть Yandex Cloud (точно?). Если нет — регистрация в https://cloud.yandex.ru/ → SpeechKit API
3. **SIP-номер 7-3842-63-55-88** — переадресация на Voximplant
   - Это техническая настройка через текущего оператора
   - Или взять виртуальный номер прямо у Voximplant
4. **Anthropic API key** — у нас он уже нужен для текстового робота
