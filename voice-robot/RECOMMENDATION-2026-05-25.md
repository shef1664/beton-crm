## Рекомендация: 🟢 Вариант 3 — Voximplant + Yandex SpeechKit + Claude API

### Почему именно этот

| Критерий | Почему важно для Бетон42 |
|---|---|
| **Один промпт с текстовым ботом** | У нас уже работает `qualify-leads.py` на regex + Claude. Голосовой бот будет переиспользовать ту же логику и тот же набор полей (volume / grade / address / date / urgency). Один источник правды → меньше расхождений в скриптах. |
| **Yandex TTS** | Лучший голос русской речи на рынке — клиент в Кемерово не услышит «робот». Бетон — продукт где доверие важно. |
| **152-ФЗ полностью соблюдён** | TTS/STT в РФ, OAuth и юр.лицо тоже. Не нужно VPN-прокси, нет валютных рисков, нет «уйдёт ли OpenAI с рынка завтра». |
| **Стоимость ~40 ₽ за звонок 5 мин** | Сопоставимо с Voximplant Avatar, но даёт качество как у OpenAI Realtime. CPL контролируем. |
| **Нет vendor lock-in** | Каждый компонент заменим (Voximplant → MTT/Beeline SIP, Yandex → MTS Exolve, Claude → GPT). |

### Почему НЕ остальные три

- **Variant 1 (Voximplant Avatar)** — vendor lock-in, средняя LLM (ниже Claude), нет общего промпта с текстовым ботом. Дешевле на бумаге, дороже в долгосрок.
- **Variant 2 (Voximplant + OpenAI Realtime)** — лучший голос-в-голос, но 152-ФЗ риск (данные клиентов в США), требует VPS-прокси в Европе ($10/мес минимум), OpenAI блокирует российские IP и платежи. Дорого ($0.18/мин ~ 18 ₽), валютный риск.
- **Variant 4 (Aimylogic)** — no-code, быстрый старт, но vendor lock-in и фикс 5000₽/мес даже при 0 звонков. Имеет смысл только как 2-3 недельный пилот, если очень хочется завтра запустить голос.

## Цены — проверка на актуальность май 2026

Проверено по официальным страницам 2026-05-25: Voximplant pricing, Yandex Cloud SpeechKit pricing, Aimylogic pricing.

| Компонент | Цена в STACK-COMPARISON (январь) | Май 2026 (актуально) | Комментарий |
|---|---|---|---|
| Voximplant SIP | 3–5 ₽/мин | 3.5 ₽/мин входящий | Цена в РФ-зоне стабильна |
| Yandex SpeechKit STT | 0.2 ₽/мин | 0.24 ₽/мин | Премиум-распознавание (рекомендуется для речи клиента) |
| Yandex SpeechKit TTS premium | 0.6 ₽/мин | 0.65 ₽/мин | Голос Alena/Filipp — норма |
| Claude API (Haiku 4.5) | 5–10 ₽/диалог | 4–8 ₽/диалог | Haiku 4.5 покрывает квалификацию-3 поля без проблем |
| Виртуальный SIP-номер | — | от 250 ₽/мес | Если шеф хочет отдельный номер для бота |

**Итог за 5-минутный звонок:** 17.5 (SIP) + 1.2 (STT) + 3.25 (TTS) + 6 (Claude) = **~28 ₽**.
Дешевле чем январская оценка (40 ₽) — за счёт перехода на Haiku 4.5 и оптимизированных тарифов SpeechKit.

При **100 звонках в день** — 2 800 ₽/день ≈ 84 000 ₽/мес операционных расходов на робота.
Окупаемость: 1 закрытая сделка в неделю = +60-80 тыс. ₽ маржи → робот окупает себя при 0.5 сделок/нед, что заведомо ниже воронки.

## Блокеры (что от шефа)

1. **Voximplant аккаунт** — регистрация на https://manage.voximplant.com/registration. Нужны: реальная российская симка для SMS-верификации, e-mail юр.лица. Регистрация даёт $25 на тесты.
2. **Yandex Cloud + SpeechKit API key** — у нас уже есть Yandex Direct/Webmaster, аккаунт активен. Включить SpeechKit и взять API key (на это требуется привязка карты для биллинга, даже если потребление маленькое).
3. **Anthropic balance** — на момент 2026-05-25 баланс = 0. Перед запуском пополнить минимум на $20 (хватит на 1-2 недели голосового бота).
4. **Решение по SIP-номеру:**
   - Вариант А (рекомендую): перевести входящие с 8 (3842) 63-55-88 на номер Voximplant через переадресацию у текущего оператора. Затраты: 0 ₽, делается за 1 звонок оператору.
   - Вариант Б: купить виртуальный номер у Voximplant и постепенно переводить на него рекламу. Затраты: 250 ₽/мес. Дольше, но безопаснее (можно откатиться).
5. **Согласие на запись звонков** — это юридически обязательно (статья 23 Конституции РФ + 152-ФЗ). Бот должен в первую фразу говорить: *«Звонок записывается в целях контроля качества. Это бот компании Бетон42, через 30 секунд переключу на менеджера если потребуется».* Шефу подтвердить формулировку.
