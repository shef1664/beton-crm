# Яндекс.Директ — план запуска кампаний для бетон42.рф

ООО «ПУЛЬСАР», бренд «Бетон Экспресс», регион **Кемерово и область** (geo_id 64).
Сайт: https://бетон42.рф · backend пишет UTM в кастомные поля AmoCRM воронки.

> ⚠️ **Не запускать без выполнения 3 предусловий:**
> 1. Уведомление в Роскомнадзор подано (152-ФЗ ст. 22)
> 2. Яндекс.Метрика на сайте с настроенными целями («submit_lead», «click_to_call»)
> 3. Маркировка рекламы в ОРД (ст. 18.1 ФЗ «О рекламе», действует с 2022)
>
> Без этих шагов любой рекламный трафик создаёт штрафы. Подробнее — `AGENTS.md` → TODO красная зона.

## Тестовый запуск — 7 дней, бюджет 7 000 ₽

Перед боевым стартом — мини-тест:

1. Только **Кампания 1 (Флагман)**, **Вариант A** объявления
2. Бюджет: **1 000 ₽/день × 7 дней = 7 000 ₽**
3. Гео: **только Кемерово** (без области, чтобы быстрее накопить данные)
4. Цель: накопить **минимум 30 кликов** для понимания CTR и CR

**Что мерить:**
- CTR > 5% — текст работает
- CTR 2–5% — нужен А/B
- CR (клик → форма) > 2% — лендинг работает
- CR <1% — лендинг или ставка не та

После 7 дней — масштабируем то что взлетело.

## Что мне нужно от пользователя для запуска

1. **Counter ID Яндекс.Метрики** — для целей и ретаргетинга (см. отдельный файл `YANDEX_METRIKA_SETUP.md`)
2. **OAuth токен Яндекс.Директ** (scope `direct:api`) — для автоматизированного создания кампаний/объявлений через API. Без токена — придётся вручную в Директе создавать. С токеном — я генерирую JSON-payload и пушу за минуты.
3. **Бюджет на тест** — 7 000 ₽ на 7 дней или сразу полный 105 000 ₽/мес.
4. **Реквизиты для пополнения** — карта/юр.счёт Яндекс.Директа

## После запуска

1. Ежедневный мониторинг первые 7 дней (CTR, CPC, конверсии)
2. Через 7 дней — анализ и масштабирование/откат
3. Параллельно — Авито через avito-monitor + Яндекс.Карты/2ГИС (через ru-sales-stack skill)
4. UTM-разрез в AmoCRM покажет какая кампания приносит реальные сделки (не просто лиды) → дальше масштабируем только прибыльные
