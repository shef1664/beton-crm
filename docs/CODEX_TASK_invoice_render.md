# ТЗ Кодексу: включить счета в @otdprod_bot на Render (секреты вне git)

Генератор счетов встроен в backend (`backend/invoice_generator/`) и подключён к
клиентскому боту `@otdprod_bot` командой **/schet**. Код уже в master-ветке. Реквизиты
организаций и печати в git НЕ лежат (репозиторий публичный) — их нужно положить как
**Render Secret Files** и включить деплой.

## 1. Секретные файлы (Render → сервис beton-backend → Environment → Secret Files)
Папка по умолчанию `/etc/secrets` (env `INVOICE_SECRETS_DIR`). Добавить файлы:

- **`seller.sequoia.json`** — реквизиты ООО «Секвойя» (содержимое — из присланного
  Клоду zip `invoice-changes-sequoia.zip` → `config/seller.sequoia.json`, или из локального
  проекта `invoice-generator-for-claude/config/seller.sequoia.json`). НЕ вставлять в git.
- **`seller.pulsar.json`** — реквизиты ООО «Пульсар» (если нужен второй продавец;
  из того же места). Опционально.

> Формат имени строго `seller.<ключ>.json`. Ключ = как выбирать продавца
> (`sequoia`, `pulsar`). Продавец по умолчанию — `sequoia` (env `DEFAULT_SELLER_KEY`).

### Печати
Печать организации — файл `<ключ>-stamp-signature-pdf.png` в той же папке
(напр. `sequoia-stamp-signature-pdf.png`). Печати **Секвойи пока нет** → счёт печатается
с подписью без печати (это ок). Когда пришлют печать Секвойи:
- Render Secret Files — текстовое поле, бинарный PNG туда неудобно. Варианты:
  1. подключить **Render Disk** (персистентный), положить PNG туда и указать
     `INVOICE_SECRETS_DIR` на этот диск; либо
  2. хранить печать base64 в secret-файле и декодировать при старте (скажи — добавлю хук).
- Печать привязана к организации по ИНН: печать Пульсара НЕ попадёт в счёт Секвойи.

## 2. Переменные окружения (уже в render.yaml, проверить значения)
```
INVOICE_SECRETS_DIR=/etc/secrets
DEFAULT_SELLER_KEY=sequoia
INVOICE_OUTPUT_DIR=/tmp/beton-invoices
DADATA_TOKEN=<есть>            # поиск покупателя по ИНН (название/КПП/адрес)
# Роутинг моделей AI-консультанта (не про счета, но в этом же деплое):
AI_MODEL=                      # ПУСТО = включён роутинг по сложности
AI_MODEL_COMPLEX=claude-fable-5
AI_MODEL_MEDIUM=claude-opus-4-8
AI_MODEL_LIGHT=claude-haiku-4-5-20251001
```
> Нумерация счетов хранится в `INVOICE_OUTPUT_DIR` и сбрасывается при рестарте
> (ФС Render эфемерна). Нужна сквозная нумерация — подключить Render Disk и указать
> `INVOICE_SEQUENCE_PATH` на него.

## 3. Деплой и зависимости
`backend/requirements.txt` уже включает `reportlab` и `qrcode`. Задеплоить latest master
(`beton-backend`), дождаться `live`.

## 4. Проверка
1. Логи старта: бот поднялся, без трейсбеков `invoice`/`reportlab`.
2. В `@otdprod_bot`: `/schet` → инструкция. Отправить:
   ```
   Инн 5405042760
   Бетон М300 6м3 7200
   Услуги доставки 1 6000
   ```
   → придёт **PDF-счёт от ООО «Секвойя»** (логотип Бетон Экспресс, QR по ГОСТ,
   итог 49 200 ₽), копия — в группу отдела продаж.
3. `Организация: Пульсар` первой строкой → счёт от Пульсара (с печатью, если её файл залит).
4. `/start` — выход из режима счёта, обычный AI-диалог продажи работает как прежде.
