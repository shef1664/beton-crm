# Yandex.Direct payloads

Готовые JSON-payload для пуша через Direct API v5. Когда у нас будет OAuth-токен со scope `direct:api`, всё запушится одной серией `curl`.

## Что внутри

| Файл | Назначение |
|---|---|
| `campaigns.json` | 4 кампании (Флагман / Мини-миксер / Раствор / Автонасос) с бюджетами и стратегиями |
| `keywords.json` | 68 ключевых фраз сгруппированных по кампаниям |
| `ads.json` | Тексты объявлений (3 варианта во Флагмане для A/B, 1 в остальных) + быстрые ссылки |

## Бюджет

| Кампания | ₽/день | ₽/мес |
|---|---:|---:|
| Флагман | 1500 | 45 000 |
| Мини-миксер | 800 | 24 000 |
| Раствор | 500 | 15 000 |
| Автонасос | 700 | 21 000 |
| **ИТОГО** | **3 500** | **105 000** |

## Порядок пуша (когда будет OAuth токен)

1. `Campaigns.add` → получить `campaign_id` для каждой из 4 кампаний (записать ID в keywords/ads).
2. `Campaigns.update` → выставить `Geo: [64]` для каждой (Кемеровская область).
3. `AdGroups.add` → создать по 1 группе в каждой кампании.
4. `Keywords.add` → загрузить 68 ключей в соответствующие группы.
5. `Sitelinks.add` → создать набор быстрых ссылок.
6. `Ads.add` → загрузить 6 объявлений (3 во Флагмане + 1 в каждой из остальных).
7. `Campaigns.archive=false` → активировать.

## Тестовый запуск (7 дней, 7 000 ₽)

Перед боевым стартом — только Флагман, только вариант A, бюджет 1 000 ₽/день × 7 дней. Цель: 30+ кликов, понять CTR и CR. Подробнее в `docs/YANDEX_DIRECT_LAUNCH_PLAN.md`.

## Что нужно от пользователя для активации

1. **OAuth токен Яндекс.Директ** (scope `direct:api`):
   - https://oauth.yandex.ru/ → создать приложение
   - Доступы: Яндекс.Директ → Управление кампаниями
   - Получить access_token
   - Пришлю токен → пропишу в `~/.secrets/yandex-direct.json`

2. **Подтверждение бюджета:** 105 000 ₽/мес или сразу тест 7 000 ₽ на 7 дней.

3. **Пополнение баланса Яндекс.Директа** на сумму бюджета через кабинет direct.yandex.ru.

После этого — серия curl-команд по порядку из «Порядок пуша» создаст всю структуру за ~2 минуты.
